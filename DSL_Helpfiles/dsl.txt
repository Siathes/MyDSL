(DSL) Dark & Shattered Lands
DSL is a Diku/Merc/Rom based mud. We have re-written the majority
of thier code and added our own versions of part of it. The current
product of our code is currently called DSL 3.03. DSL would like to
thank Diku, Merc, and Rom for their excellent source contributions.
Code contributions were made by Scorn, Curumo, Istiak,
Ashlar, Vaelin, Avachel, Estel, Bioteq, and Connor.
